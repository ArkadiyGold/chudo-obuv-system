# Информационная система «Чудо Обувь»

## Описание
Приложение для автоматизации работы торговой компании «Чудо Обувь». Система позволяет вести каталог товаров, управлять складскими остатками, оформлять заказы и разграничивать права доступа пользователей.

## Стек технологий
- Python 3.11
- PostgreSQL
- PyQt5 (графический интерфейс)
- pandas (обработка данных)
- psycopg2-binary (работа с БД)

## Структура проекта
```
chudo_obuv_project/          # Корневая папка проекта
├── main.py                  # Главное приложение
├── import_data.py           # Скрипт импорта данных
├── Images/                  # Изображения товаров
├── Orders_import.xlsx       # Исходные данные о заказах
├── Products_import.xlsx     # Исходные данные о товарах
├── Sizes_import.xlsx        # Исходные данные — справочник размеров
├── Stock_Items_import.xlsx  # Исходные данные — складские остатки
├── Users_import.xlsx        # Исходные данные о пользователях
├── picture.png              # Заглушка для товаров без фото
├── Чудо Обувь.png           # Логотип
└── Чудо Обувь.ico           # Иконка приложения
```

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install PyQt5 pandas openpyxl psycopg2-binary
```

### 2. Настройка базы данных
1. Создайте базу данных `chudo_obuv` в PostgreSQL
2. Настройте подключение в файлах `main.py` и `import_data.py` (переменная `DB_CONFIG`)

### 3. Импорт данных
```bash
python import_data.py
```

### 4. Запуск приложения
```bash
python main.py
```

## Функциональность

### Каталог товаров
- Просмотр каталога с изображениями, категориями, ценами
- Автоматический расчет скидки 25% на товары без заказов в предыдущем месяце
- Подсветка товаров с остатком ≤ 3 пар красным цветом
- Фильтрация по категории, сортировка по цене, поиск по названию

### Оформление заказа
- Авторизация по логину (без пароля)
- Выбор товара, размера и количества
- Автоматическое уменьшение остатков на складе
- Сохранение истории заказов

### Управление заказами (для Менеджера и Администратора)
- Просмотр списка всех заказов
- Детальная информация о составе заказа
- Редактирование заказов (только Администратор): изменение даты, удаление позиций
- Автоматический возврат остатков при удалении позиций

### Роли пользователей
- **Администратор**: полный доступ ко всем функциям
- **Менеджер**: просмотр и управление заказами
- **Авторизованный пользователь**: оформление заказов
- **Неавторизованный пользователь**: только просмотр каталога

## Требования к интерфейсу
- Шрифт: Calibri
- Цветовая схема: белый фон (#FFFFFF), мятный дополнительный (#D2F6E7), бирюзовый акцент (#70B2AF)
- Подсветка низкого остатка: светло-красный (#FF8080)
